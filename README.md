# YaKyoLife 全路線事件解答器

這不是固定事件表，而是跟著目前遊戲路線同步的本機 Chrome 擴充套件。

它會在每張事件卡出現時顯示：

- 當張事件的固定 RNG 值
- 全力一搏、照常執行、保守應對各自必定成功或失敗
- 能成功的最大收益選項
- 目前的「自律狂」保守成功計數，以及本張能否增加計數
- 三種都失敗時，提示選保守降低損失
- 緋聞承認是否會成功交往
- 外遇／劈腿這次會不會被抓，以及長期安全選擇
- 被抓後道歉能否成功；失敗時提示直接離婚／分手以免再扣能力
- 求婚事件的固定最佳選擇

## 安裝

1. 在 Chrome 網址列輸入 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點「載入未封裝項目」。
4. 選擇整個 `yakyolife-event-solver` 資料夾。
5. 確認擴充套件已啟用。
6. 重新開啟 `https://www.yakyolife.com/?seed=ofaelz`，從新的一局開始。

## 重要限制

- 必須在遊戲頁載入之前啟用，因為工具要從第一個 RNG 呼叫開始計數。
- 不能在已經玩到一半的頁面中途安裝；那會缺少前面的 RNG 次數。
- 安裝後如果遊戲已經開著，請重新整理並重新開局。
- 種子、位置、加點、大賽結果、傷病、學院派、大巧不工與所有職涯分支都可以不同；工具會依實際路線計算。
- 工具只在本機讀取遊戲畫面與 RNG 次數，不會傳送資料。

## 如何看提示

- 綠框：能成功的最大倍率，直接選它可取得當張事件最大正收益。
- 紅框：三種選項都必敗，選保守可把減益與受傷風險降到最低。
- 若目標是自律狂，提示會顯示目前 `幾次/15`、還差幾次、本張選保守後會變成幾次、25 歲截止前還有多少事件格，以及理論上還能選大幾張。
- 截止前事件格會依已確定的目前路線計算；尚未選定的未來升學／職業分支會顯示最少～最多範圍，並假設沒有整季報銷。
- 感情選項會用綠框標示長期最佳解；橘框代表這次固定不會被抓、短期收益較高，但會累積外遇次數及其他隱藏風險。
- 加點畫面會依目前能力、蓄力進度、升級成本、潛力與守位即時重算；學生／企業隊以 OVR 為目標，職業則以球隊奪冠實際採用的核心評分為目標。
