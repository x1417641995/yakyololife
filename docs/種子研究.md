## 搜尋結果

曾依官網 RNG 演算法搜尋約 22 億個候選字串，沒有找到在「Contact 80、力量 80」的同時，其餘六項潛力全部不低於 `ofaelz` 且至少一項更高的严格支配種子。

因此在該次搜尋範圍內：

- 若要求六顆骰全部是六點，`ofaelz` 仍是找到的最佳代表
- `z8ur953` 是 RNG 雜湊碰撞，開局結果與 `ofaelz` 完全相同
- 以下候選能提高部分能力，但必定犧牲其他項目

## 重要限制

種子只固定 RNG 串流。不同位置、加點、升學、賽事结果、傷病、感情及職涯选择會消耗不同 RNG，後續事件不能只靠種子名稱做成一張通用靜態表。實際事件答案應使用本 repo 的即時解答器。
